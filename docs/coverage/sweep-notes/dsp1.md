# SPEC-SWEEP Phase 2 notes: dsp1

- [SP-17 / ISS-2] `pickup_blend` is a centre-detent blend between the two outermost switched-in pickups (0 = bridge side alone, 1 = neck side alone, 0.5 = both at full level). Why: 0.5 is the parameter's default, so every existing preset and switch position sounds as before. With one pickup on it does nothing. The knob sits beside the selector in ADVANCED col 2 PICKUPS.
- [CW-17] The tone-cap drift is scaled by the master character amount (`CharacterEngine::getToneCapMultiplier`), like every other per-seed deviation. Why: the default amount (0.25) should not put a full +/-5 % on every guitar. `capacitorDriftRange` still sets the per-seed maximum.
- [CW-18] The jack dropout's gain is read once per block (CharacterEngine advances per block) and ramped with a 3 ms one-pole. Why: character-wear rule 2 keeps character off the per-sample path. A 20 ms dropout inside a 2048-sample host block lasts one block.
- [CW-19] The piezo path now sums the strings through the per-saddle gains. At 0 dB it is bit-identical to the old string sum.
- [CW-22] The saddle-height intonation offset is 1.5 cents per mm at the 12th fret, scaled by 2(1 - 2^(-fret/12)), and 0 open. Why: at the spec's +/-0.2 mm the offset is "minute", as the spec says. The constant is a calibration, not a measurement.
- [CW-12] A worn fret adds `(multiplier - 1) x 0.1 mm` to the buzz contact excess at the fretted position. Why: a worn crown sits lower, so the string is closer to the next fret. With `FretBuzz::process`'s default `nullptr`, behaviour is unchanged.
- [CW-24] The body-age multipliers are multiplied into realism-a's `setRuntimeScaling` arguments: air frequency x `getAirResonanceMultiplier`, plate Q x `getBodyQMultiplier` / `getBodyHfDampingMultiplier`. Why: damping is 1/Q, and the engine has no separate HF-damping hook. The default (age 20, amount 0.25) moves the air mode by -0.275 %, so `Environment::ENV04` and `PartAcoustics::chamberingReachesTheBodyEngine` turn character off to isolate what they measure.
- [PA-14/15/56] Chambering's air mode, air Q and mode gain, and the finish's top damping, reach `BodyModels::buildModes` through four new neutral `BodyConfig` fields (`airHzOverride`, `airQOverride`, `modeGainDb`, `topDampingDb`) set in `mapSpec`. The chambering mode gain applies to electric chamberings only. Why: an acoustic's body is its whole mic signal, not a colour against solid, and +14 dB would only fight the output normalisation. A compiled (non-Workshop) guitar is unchanged.
- [PA-56] Acoustic bodies default to Convolution mode, so the finish damping is heard in Modal/Hybrid body mode only (the IR is a recording).
- [PR-44 / AR-15] The modulation family clamps in the source setters (`Modulation/ModRanges.h`). A source constructed on its own is locked (stock). `ModMatrix::setModulationRangeAdvanced` is synced from `setRanges`, at the end of every preset load (`onGuitarBlockLoaded`), and before each `modMatrix.fromVar`. Why: an unlocked 100 Hz LFO then survives a state or preset round trip. Envelope delay and hold are not in the 3.4 table and keep 0-30 s.
- [PR-44] The envelope's stock attack/decay/release maximum is now 5 s (it was 30 s), as the 3.4 table says. A preset with a longer envelope time clamps unless its modulation family is unlocked.
- [MM-10 / MM-6 / MM-T3 / MM-50] DEFERRED to the worker doing RIO-30. Those items ride on its `PresetManager` extra-blocks hook, and a second hook would collide.
- [MM-41] The row was wrong: `Modulation::routeModulatesItsDestination` already checks that a disabled route contributes nothing.
- [FactoryPresets] Fixed a use-after-free. `FactoryPresets::rangeSource` outlived its processor, and the next processor's `PresetManager` constructor called `writeAll` through it (a segfault in the sweep's test runs). The processor destructor now clears it.
- [TuneIntegration::aSnapshotRecallsTheTunesSection] This test fails on the merged tree, run alone, with or without these changes. It comes from the TUNE-HELP merge and is not this branch's.
- [PA-40] The coil_turns reference windings are 8000 (single coil), 10000 (P-90) and 5000 per coil (humbucker). The dB offset adds to output_dbfs_reference. Why: a part that states only its turns then lands at its family's default level.
- [MM-8] Transport start resets the envelopes, followers and random sources. LFOs restart per their own retrigger mode, and a free-running one is exempt. Why: section 1.1 makes free-run a per-source option, and restarting it on transport start would defeat that option.
- [MM-6] `ModMatrix::fromVar` used to call `reset()` on the message thread, racing the audio thread's tick. It now sets `sourceResetPending`, and the next `processBlock` restarts the sources. Offsets are not zeroed, because the next tick recomputes them.
- [RIO-6] The monitor bus (Aux 7) is not required to sound. Live-performance's monitor path feeds it, and with no monitor send it is legitimately silent.
- [EN-50] The pickup slot-gain smoother's time constant is now 5 ms / 4.6. Why: the old tau of 5 ms still left 37 % of the old pickup 5 ms after a switch, while engine.md 7.7 asks for a 5 ms crossfade. A switched-off pickup's comb history now keeps being written, so switching one in starts from its real state rather than from silence.
