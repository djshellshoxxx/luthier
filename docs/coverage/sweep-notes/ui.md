# SPEC-SWEEP notes - ui worker

- [LP-11/LP-14/LP-41] Live-action CC assignments (next/prev/by-value snapshot, tap, kill, panic, setlist next/prev) are user-global in `~/Documents/Luthier/config/live-actions.json`, like pedal calibrations (live-performance 11 already makes calibrations global) - they describe the footswitch on the floor, not the sound. The per-preset-by-default rule of §11 for *parameter* MIDI Learn (LP-41) is left open: it needs a `midiMappings` preset block and a "global" flag in `MidiLearnManager`, which the visual branch reworks heavily.
- [LP-11] A CC assigned to a live action is removed from parameter MIDI Learn (one CC, one meaning); live actions are consumed on the MIDI path so the engine never sees the footswitch as a controller. Press = value >= 64; kill is momentary on the same threshold.
- [LP-16] Snapshot morph is the automatable parameter `snapshot_morph` (appended in the SPEC-SWEEP block). The processor's 30 Hz timer follows it (raw value + mod-matrix offset) and calls `SnapshotBank::setMorphPosition`, because the morph writes parameters and cannot run on the audio thread. The parameter is never captured into or restored from a snapshot.
- [LP-5] The Live strip's setlist menu no longer offers "Open a setlist file..." (a FileChooser); it lists the setlists in the user folder. Loading from anywhere else stays on the LIVE tab.
- [LP-31/GI-119] Monitor level/pan/EQ live on the LIVE tab (MONITOR section) rather than the ROUTING panel: that panel is being reworked on the visual branch and the LIVE tab is the setup surface for the Live strip (gui-integration 4.4). Monitor mix settings are still session-only (not saved in state) - pre-existing, left open.
- [LP-39/GI-76] Live Mode suppresses all tooltips (no "critical" exception): the Live strip's controls are self-describing and a tip over the snapshot strip mid-song is noise.
- [A11Y-27] Font floor raised from 9 to 10 (accessibility 4: "never below 10 px effective at 100%"); test updated.
