## guitar-illustration.md

The renderer is substantial and the visual-branch work is now merged (`UI/Guitar/GuitarRenderer.*`, `BodyOutlines.h`, `HeadstockOutlines.h`, `GuitarThumbnails`, `IllustrationMotion.h`; `IllustrationRemainderTests.cpp`, `WorkshopRemainderTests.cpp`): thumbnails, note dots, crossfade, zoom, reverse headstocks, string overrides and the nut/pick/slide/capo drags are DONE. Remaining gaps: factory body parts carry no `illustration.body_style` (a body swap never changes the outline), no finish/hardware editor, no buzz-heatmap or pickup-pulse layer, no drawer drag-and-drop or Shift+click-below, `pole_spacing_mm` unread, pinless / bass-mute / ferrule / pearloid / compound-radius / vine not drawn, and several drawing rows untested.
