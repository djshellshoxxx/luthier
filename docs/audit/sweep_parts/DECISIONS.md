## DECISIONS.md

DECISIONS.md is the log of judgement calls. Most of them are in the code and tested on this checkout. The model-gaps merge closed the old gaps: block-boundary part swap, capture technique hooks, the rhythm bass-pattern setting, retiring `selectNotesForStyle`, and the STRUM rows that had zero height. The file is out of date in places: it still says the phase-2b specs are "not on disk" (they are, and realism-a/b/c own them), and C-32's TECHNIQUES tab is not built (the strip has 14 other tabs). Still open here: C-19 `.luthierkit` files, the winding selector's move to the Workshop string part, the part fields nothing consumes, the Workshop swap overwriting SETUP tweaks, per-control unlock clearing and the locked-edge bubble (no test for either), and the MIDI chuck key range.
