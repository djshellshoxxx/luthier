## jam-mode.md

Jam mode is implemented on this checkout (see docs/coverage/FEAT-JAM.md): `Source/Jam/` (engine, style, chord follower, bass line, capture, MIDI export), `Source/DSP/Jam/` (drum kit, bass voice), 34 `jam_*` parameters, the JAM tab (`UI/JamPanel`, `JamLaneView`), Easy strip group and Live pill, Aux 9/10 outputs and JM-01..51 tests. Remaining gaps: Export MIDI uses a save chooser rather than the midi-export range dialog, PROG looper as a chord source is deferred, and the Free/Pro build split is not wired (no edition framework).
