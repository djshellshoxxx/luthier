## accessibility.md

The settings model is complete and tested: six palettes (contrast-checked), the six UI scale steps, reduced motion, verbosity, font override, 15 offered locales with named placeholders and English fallback, and a rebindable, searchable shortcut table that the editor's `keyPressed` really dispatches through. The UI scale is applied (`setScaleFactor`), attached controls are named, meters/snapshot strip/quality badge expose handlers, overlays announce, and reduced motion reaches the data stream, illustration and guitar body. Still open: font override and `stepScaleDown` are not consumed, the Fretboard has no accessibility handler, almost every UI string is a literal (about 65 `tr()` calls, no `Resources/i18n` or `Resources/Themes`), locale switching does not refresh built components, and screen-reader, locale, bidi and CJK tests are missing.
