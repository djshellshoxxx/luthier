## accessibility.md

The settings model is complete and tested: six palettes (contrast-checked), the six UI scale steps, reduced motion, verbosity, font override, 15 offered locales with named placeholders and English fallback, and a rebindable, searchable shortcut table that the editor's `keyPressed` really dispatches through. Most of the *effects* are not wired on this checkout: the UI scale is stored but never applied, knobs carry no accessible name, verbosity and font override change nothing, meters/fretboard/snapshot strip expose nothing to screen readers, overlays do not announce, and almost every UI string is a literal (12 `tr()` calls in UI code, no `Resources/i18n` or `Resources/Themes`). The visual branch applies the scale, names every attached control, adds reflow and reduced-motion effects and their tests (OWNED); screen-reader, locale, bidi, CJK and Tab-walk tests are missing everywhere.
