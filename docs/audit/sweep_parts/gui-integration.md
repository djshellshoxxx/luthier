## gui-integration.md

The Easy layout, the four-column Advanced layout, the 13 Col-4 tabs, the Options overlay (11 pages), Workshop bench, Live strip, Practice drawer, notification banners and the rebindable shortcut registry are all built and mostly tested. The biggest gaps on this checkout are in the header strip, which has no snapshot strip, no input/output meters, no tap, and no gear/dice/reset icons. Several cross-cutting rules are also missing: panel collapse/status line, empty-state hints, per-source mod arcs, "Assign to macro", panel right-click menus, Live-mode tooltip suppression and footer voice count. So is a CHARACTER -> CIRCUIT mirror, and about 30 params have no control at all (scrape_* 14, string-slap slap_* 13, macro 7/8, pickup_blend), so `GuiReach::everyAutomatableParameterHasAVisibleControl` cannot pass. The visual branch already covers a lot of the rest: ? icons, NEW dots, drag-to-modulate, UI scale + reflow test, W, the undo boundaries/grouping, right-click items 12-13, Appearance/Diagnostics/File-locations pages, the data stream and the Workshop accessories. tune-help owns Ctrl+T, drawer persistence and the tune rows.
