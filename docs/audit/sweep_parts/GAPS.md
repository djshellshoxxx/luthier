## GAPS.md

GAPS.md is the old gap list against gui-integration §19. The file says it is the least reliable document on what exists, and it has gone stale further since: every "blocked" module (GuitarCircuit, Workshop, Slide, NoiseEngine, STRUM, advanced ranges, SLAP / bass grid) is built, the column-4 strip has 14 tabs (no TECHNIQUES), Options has all eleven tabs including RANGES, and the missing-guitar and missing-part banners work. Still open: per-string detune as automatable parameters, expression calibration on the LIVE tab (Options only), Space driving the tune transport (TUNE only while focused), and tests for the §4.5 column widths, the digit snapshot keys and the old rhythm-state capo. The accent / data-stream / noise-strip toggles, flag mirror, `W` and drag-to-assign have landed and are tested; the changelog viewer and Guitars/Parts folder buttons exist without a UI test.
