## file-formats.md

Parts, guitars, tunes and `.midprofile` follow the spec: `schema` and `magic`, a `meta` block, unknown-field preservation for tunes, and temp-then-rename saves. The preset format still drifts. It has a flat root with `schemaVersion` (a missing one is refused, not read as 1) and no `meta` block. Modulation, snapshots, MIDI Learn mappings, rhythm and routing are left out; those survive only in the host state. The migration backup to `Presets/Backup/<date>/<name>-v<schema>` has landed from model-gaps and is tested. Setlist and loop files use a `format` string instead of `magic`/`schema`, pattern and kit files have neither, and the UI has no way to save a setlist. `.luthiercontent` (engine + tests, no install UI) and the guitar `per_string_override` are merged; the every-byte fuzz tests exist for presets, guitars and tunes. The atomicity and 200-fixture migration tests still do not exist.
