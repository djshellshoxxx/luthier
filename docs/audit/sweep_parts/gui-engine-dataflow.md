## gui-engine-dataflow.md

Most live elements exist and read their data by polling engine accessors or atomics from component timers, not through a display FIFO. Drain rates now follow the spec (fretboard/illustration 60 Hz, routing meters/circuit 30 Hz, mod arcs 30 Hz via a shared hub; the noise strip stays 30 Hz per string-squeak 9.1). Stale states exist for the heatmap, noise strip, valve glow, output LED, slide bar, chord readout and string animator, not for the rest. Tested elements include the output LED, chord dim, next-strum arrow, looper LED, session bar, MIDI Learn pulse and thumbnails. Still missing: the header input/output meters, the pickup pulse, the voice count, a header tap LED, per-source mod-arc segments, a per-element `Tests/Ui/Dataflow/` suite and the Diagnostics data-flow overlay. The data stream, note dots, pick overlay, reduced-motion noise count and preset-browser thumbnails are merged and tested.
