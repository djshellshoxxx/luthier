## Signal chain, stage by stage
Partially corroborated only (search snippets; no schematic could be read in this session):
- Topology: JFET bypass, input buffer, non-inverting op-amp clipping stage with diodes in the feedback loop and a clean bleed, tone/volume stage, output buffer (ElectroSmash; PedalPCB).
- Op-amp usually JRC4558D/RC4558P; clipping diodes MA150 (forum, single-source).
- Input cap 0.02 uF; output resistors 100R and 10k (DIYstompboxes, one source).
- Pre/post clipping corner described as ~720 Hz (PedalPCB, unverified).
