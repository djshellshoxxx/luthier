# Pedalboard

The reference pedalboard is a separate effects subsystem from the two eight-slot pedal racks in the Advanced panel. It holds up to 16 pedals, is off until you switch it on, and offers 13 registered models (10 generic effects and 3 prototypes).

The six named models planned for the first pedalboard release (a phaser, two bucket-brigade choruses, a digital delay, a compressor and a looper) exist as unregistered prototypes and are **not available**. The pedalboard is not release-qualified.

- Open it with the header button or Ctrl+Shift+B (Cmd+Shift+B on macOS). It pops out by default; it docks only when the editor is at least 840 pixels tall.
- Full guide, with keyboard operation, MIDI learn and signal-chain placement: [PEDALBOARD.md](https://github.com/djshellshoxxx/luthier/blob/master/docs/PEDALBOARD.md).
- Controls of each model: [EFFECTS_REFERENCE.md](https://github.com/djshellshoxxx/luthier/blob/master/docs/EFFECTS_REFERENCE.md).
- Status: [Known Issues](https://github.com/djshellshoxxx/luthier/blob/master/docs/KNOWN_ISSUES.md), section "Pedalboard".
