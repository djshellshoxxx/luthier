# Release Procedure

Canonical: [RELEASING.md](https://github.com/djshellshoxxx/luthier/blob/master/docs/RELEASING.md): what CI does, running CI locally, what gets installed where, signing secrets, cutting a release, manual checks, rollback. No public release has been made from the current source, and signed installers need credentials that are not in the repository.

**Hazard:** a workflow publishes a beta when a particular pull request is closed as merged. See the release hazards section of RELEASING.md before merging an integration branch to master.
