# Guitar Workshop

The Workshop tab (and an Easy-mode overlay from the header) lets you build and edit instruments from parts: click parts, drag pickups and saddles, audition parts, and compare results. The guitar on screen is drawn from the live instrument settings, so it is correct for an instrument you just built; it is a vector drawing, not a photograph ([Known Issues](https://github.com/djshellshoxxx/luthier/blob/master/docs/KNOWN_ISSUES.md)). The Free edition has no Workshop ([Product description](https://github.com/djshellshoxxx/luthier/blob/master/docs/PRODUCT_DESCRIPTION.md)).
