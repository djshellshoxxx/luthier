# Keyboard shortcuts

`Ctrl` on Windows and Linux, `Cmd` on macOS.

---

All of these are rebindable in **Options -> Accessibility**, which also lists
them with a search box, except `Escape` and the snapshot digits, which are
positional. The defaults are below.

## Global

| Key | Action |
|---|---|
| `F1` | Help |
| `Ctrl + Shift + /` | Show all shortcuts (opens the rebind table) |
| `Escape` | Close whatever overlay is open - not rebindable, on purpose |
| `Space` | Start or stop the audition phrase |
| `Tab` | Switch between Easy and Advanced |
| `L` | Live Mode on or off |
| `S` | Slide Mode on or off |
| `D` | Open or close the Practice drawer |
| `P` | Panic - stop every string immediately; settings are untouched |
| `Ctrl + Shift + P` | Reset & stop - stop the tune, loops, backing track, metronome, rhythm engine and kill switch, and return every setting to default (one undo step) |
| `T` | Tap tempo |
| `\` | Kill switch |

## Presets and snapshots

| Key | Action |
|---|---|
| `[` / `]` | Previous / next preset, or snapshot while Live Mode is on |
| `Ctrl + [` / `Ctrl + ]` | Previous / next workspace tab in Advanced mode, wrapping at the ends |
| `1` - `9` | Recall snapshot 1 to 9 |
| `Shift + 1` - `9` | Recall snapshot 10 to 18 |
| `PageUp` / `PageDown` | Previous / next setlist entry |

## File and edit

| Key | Action |
|---|---|
| `Ctrl + O` | Preset browser |
| `Ctrl + N` | New preset (loads the Init factory preset) |
| `Ctrl + S` | Save the current preset |
| `Ctrl + Shift + S` | Save As |
| `Ctrl + Alt + E` | Show the preset file on disk |
| `Ctrl + G` | Save the guitar as a `.luthierguitar` file |
| `Ctrl + Shift + E` | Show the guitar file on disk |
| `Ctrl + E` | Export audio |
| `Ctrl + L` | Arm MIDI Learn, then click a control |
| `Ctrl + Z` | Undo |
| `Ctrl + Shift + Z` | Redo |
| `Ctrl + R` | Randomise |
| `Ctrl + Shift + R` | Reset everything to defaults |
| `Ctrl + /` | A / B compare |
| `Ctrl + ,` | Options |
| `Ctrl + D` | Debug tools |

## On any control

| Input | Action |
|---|---|
| Left-drag | Adjust |
| `Shift` + drag | Coarse |
| `Ctrl` + drag | Ultra-fine |
| Double-click | Reset to default |
| Mouse wheel | Scroll the column (the control lets it through) |
| `Ctrl` + wheel | Nudge the value |
| Right-click | Enter value, Reset, Copy, Paste, MIDI Learn, Lock, Randomise |
| Hover | The value replaces the label; a tooltip follows after 400 ms |

## On the fretboard

| Input | Action |
|---|---|
| Click | Play that note - click higher in the string's lane to pick harder |
| Right-click | Mute string, select string, set capo, scale overlay |

## In the string roll

| Input | Action |
|---|---|
| Click a lane | Pluck that string - higher in the lane is a higher fret, further right is harder |
| `Enter` / `Space` | Pluck the focused lane |
## In the LIVE snapshot grid

| Input | Action |
|---|---|
| Click | Select the slot |
| `Shift` + click | Store the current sound in it |
| Double-click | Recall it |
| Right-click | Recall, capture, rename, colour tag, clear |

## On the TUNE tab

These belong to the tab and work while it has focus.

| Key | Action |
|---|---|
| `Space` | Play / pause the tune |
| `Shift + Space` | Play from the start of the current section |
| `Ctrl + T` | New tune from a template |
| `Ctrl + S` | Save the tune |
| `Ctrl + E` | Export the tune as MIDI |
| `Ctrl + Z` / `Ctrl + Y` | Undo / redo in the tune |

A `.mid` file dropped anywhere on the window is imported into the Tune Builder.

## On the guitar illustration

| Input | Action |
|---|---|
| Click a pickup | Select that pickup |
| Click the switch | Advance the selector position |
| Drag a knob | Guitar volume and tone |

## In the pedal rack

| Input | Action |
|---|---|
| Click the footswitch | Bypass the pedal, or bring it back - the label reads ON or BYPASS |
| Drag a slot onto another | Reorder |
| Right-click | Clear the slot, or reset that pedal |

## In an overlay

| Key | Action |
|---|---|
| `Escape` | Close |
| Click outside | Close |
| Click **Close** | Close |

Every overlay closes all three ways, and only one is ever open at a time.
